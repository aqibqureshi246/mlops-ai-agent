# Iris dataset

Source: scikit-learn's bundled Iris classification dataset, originally from the UCI Machine Learning
Repository. It contains 150 observations, four numerical flower measurements and three classes.

The canonical CSV is generated by scripts/prepare_data.py using pinned sklearn and pandas versions.
Data bytes are excluded from Git and tracked by data/iris.csv.dvc. A fresh clone can regenerate the
public dataset and populate its own DVC remote; historical private datasets would require actual
access to their configured remote instead.

The training procedure uses a seeded stratified split with 120 training and 30 evaluation rows.
It is a small reproducibility demonstration, not evidence of real-world model suitability.

Dataset documentation: https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_iris.html
